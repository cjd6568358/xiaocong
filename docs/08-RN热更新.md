# 08 · APP 设备面板 RN 热更新机制

> 目标：搞清楚设备详情面板（RN 写的）的 jsbundle 从哪来、怎么加载、
> 官方服务端是否还拉得到、以及我们能不能自己喂一个进去。
>
> 结论先行：**官方服务端已死，拉不到**；但热更新链路**完全不依赖官方**，
> 直接往 App 私有目录丢一个 `381785.jsbundle` 即可生效（无需改包、无需服务器）。

---

## 2. 服务端可达性（实测）

| 主机 | 用途 | DNS | HTTP 实测 |
|---|---|---|---|
| `gw.ixiaocong.com` | **API 主机（硬编码）** | ❌ NXDOMAIN | — |
| `gw.ixiaocong.net` | 调试备用主机 | ❌ NXDOMAIN | — |
| `www.ixiaocong.com` | 官网静态页 | ✅ 139.129.217.3 | `/`=200，其余全 **404** |
| `doc.ixiaocong.com` | 文档站 | ✅ 118.190.180.112 | 全 **503**（后端挂） |

API 主机在代码里两处硬编码，都指向同一个已死主机：

```java
// httplib/config/HttpContent.java
HTTP_BASE_URL = HTTP_TAG ? "https://gw.ixiaocong.com/" : "http://gw.ixiaocong.net/";
// sdk/http/XCAsyncHttpClient.java:40
url = "https://gw.ixiaocong.com/";
// sdk/network/wg/BaseWgRequest.java:26,56
```

`www.ixiaocong.com` 只是 nginx 静态落地页，对 `/device/v2/detail` 等所有 API 路径返回 404 —— **不是 API，不能顶替**。

> **结论：官方服务器确实拉不到了。** 但这不影响热更新 —— 见下节。

## 3. 三条可行路径

### 路径 A（★推荐）：直接投喂 jsbundle —— 不需要服务器

App 只认 `{filesDir}/ixiaocong/js/{productId}.jsbundle` 这个文件。设备是 `381785`：

```bash
# 需要 root，或 adb run-as（debug 包）/ 已 root 设备
adb push my-panel.jsbundle /sdcard/
adb shell su -c 'mkdir -p /data/data/com.ixiaocong.smarthome.phone/files/ixiaocong/js'
adb shell su -c 'cp /sdcard/my-panel.jsbundle \
   /data/data/com.ixiaocong.smarthome.phone/files/ixiaocong/js/381785.jsbundle'
adb shell su -c 'chown u0_aXXX:u0_aXXX /data/data/com.ixiaocong.smarthome.phone/files/ixiaocong/js/381785.jsbundle'
```

打开设备面板即加载。**无需服务器、无需改包、无需签名。**
> 图片资源放 `{filesDir}/ixiaocong/js/img/drawable-mdpi/`（代码里 `imgUrl` 指向此处）。

### 路径 B：自建 API，骗过 `device/v2/detail`

把 `gw.ixiaocong.com` 用 DNS/hosts 指到我们的机器，返回：

```json
{"code":0,"data":"{\"deviceId\":\"6587529711423210\",
  \"deviceInfo\":{\"productId\":381785,\"deviceName\":\"小葱插座\",\"isAdmin\":1},
  \"rnInfo\":{\"upgrade\":\"1\",\"version\":\"9.9.9\",
             \"downloadUrl\":\"http://<我们的服务器>/381785.zip\",
             \"fileName\":\"381785.zip\",\"md5\":\"...\"}}"}
```

App 会自动下载 `381785.zip` → 解压到 `ixiaocong/js/`。适合批量/无 root 场景。

### 路径 C：开 dev support（需改包）

`setUseDeveloperSupport(false)` 已写死。改成 `true` 后可连 Metro 开发服务器，
但需重新签名安装 —— 性价比最低，不推荐。

## 5. 复现命令

```bash
# 确认官方 API 主机已死
nslookup gw.ixiaocong.com 223.5.5.5      # → 无 A 记录
nslookup gw.ixiaocong.net 223.5.5.5      # → 无 A 记录

# 确认存活域名不是 API
curl -s -o /dev/null -w "%{http_code}\n" https://www.ixiaocong.com/device/v2/detail   # → 404
curl -s -o /dev/null -w "%{http_code}\n" https://doc.ixiaocong.com/                    # → 503

# 确认 APK 内无内置 jsbundle（assets 只有 echarts 的 tpl.html 和 test.crt）
unzip -l xiaocong.apk | grep -iE "assets/|bundle"
```
